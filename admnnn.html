⚙️ Database Setup & Fix Guide

Agar database kaam nahi kar raha — neeche SQL copy karke Supabase SQL Editor mein run karo.

Step 1: Works Table Create Karo

Supabase → SQL Editor → Neeche wala paste karo → Run karo:

-- Works table for tracking customer work status CREATE TABLE IF NOT EXISTS works ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, customer_name TEXT NOT NULL, customer_phone TEXT NOT NULL, service_name TEXT NOT NULL, status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','start','process','success')), notes TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW() ); -- Enable RLS ALTER TABLE works ENABLE ROW LEVEL SECURITY; -- Allow all operations (admin panel uses this) DROP POLICY IF EXISTS "Allow all works" ON works; CREATE POLICY "Allow all works" ON works FOR ALL USING (true) WITH CHECK (true);

Step 2: Services Table RLS Fix (Data Add Nahi Hota Fix)

Agar services add/edit/delete nahi ho raha, ye run karo:

-- Fix Services RLS policies ALTER TABLE services ENABLE ROW LEVEL SECURITY; -- Remove old policies first DROP POLICY IF EXISTS "Services are viewable by everyone" ON services; DROP POLICY IF EXISTS "Admin full access services" ON services; -- Public can read CREATE POLICY "Services readable by all" ON services FOR SELECT USING (true); -- Admin can do everything (using anon key) CREATE POLICY "Services full admin access" ON services FOR ALL USING (true) WITH CHECK (true);

Step 3: Inquiries Table RLS Fix

-- Fix Inquiries RLS ALTER TABLE inquiries ENABLE ROW LEVEL SECURITY; DROP POLICY IF EXISTS "Inquiries are viewable by admin" ON inquiries; DROP POLICY IF EXISTS "Users can insert inquiries" ON inquiries; -- Anyone can insert inquiry CREATE POLICY "Allow insert inquiries" ON inquiries FOR INSERT WITH CHECK (true); -- Admin can read all CREATE POLICY "Allow read inquiries" ON inquiries FOR SELECT USING (true); -- Admin can delete CREATE POLICY "Allow delete inquiries" ON inquiries FOR DELETE USING (true);

Step 4: Customer Data Table Create Karo (Naya)

Customer Name, Mobile, Work Type aur Date save karne ke liye. Year + Work Type se filter/count karne ke liye ye zaroori hai:

-- Customer Data table (name, mobile, work type, date) CREATE TABLE IF NOT EXISTS customer_records ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, customer_name TEXT NOT NULL, customer_mobile TEXT NOT NULL, work_type TEXT NOT NULL, work_date DATE NOT NULL DEFAULT CURRENT_DATE, notes TEXT, created_at TIMESTAMPTZ DEFAULT NOW() ); -- Index for fast year / work-type filtering CREATE INDEX IF NOT EXISTS idx_customer_records_work_date ON customer_records (work_date); CREATE INDEX IF NOT EXISTS idx_customer_records_work_type ON customer_records (work_type); -- Enable RLS ALTER TABLE customer_records ENABLE ROW LEVEL SECURITY; DROP POLICY IF EXISTS "Allow all customer_records" ON customer_records; CREATE POLICY "Allow all customer_records" ON customer_records FOR ALL USING (true) WITH CHECK (true);

Step 5: WhatsApp Poster / Broadcast Tables (Naya)

Sabhi customers ko ek saath poster/offer bhejne wale feature ke liye ye zaroori hai:

-- Poster / broadcast campaign tables CREATE TABLE IF NOT EXISTS poster_campaigns ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, title TEXT NOT NULL, message_template TEXT NOT NULL, image_url TEXT, filter_year TEXT, filter_worktype TEXT, created_at TIMESTAMPTZ DEFAULT NOW() ); CREATE TABLE IF NOT EXISTS campaign_sends ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, campaign_id UUID REFERENCES poster_campaigns(id) ON DELETE CASCADE, customer_name TEXT NOT NULL, customer_mobile TEXT NOT NULL, status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','sent','skipped')), sent_at TIMESTAMPTZ, created_at TIMESTAMPTZ DEFAULT NOW() ); CREATE INDEX IF NOT EXISTS idx_campaign_sends_campaign ON campaign_sends (campaign_id); CREATE INDEX IF NOT EXISTS idx_campaign_sends_status ON campaign_sends (status); ALTER TABLE poster_campaigns ENABLE ROW LEVEL SECURITY; ALTER TABLE campaign_sends ENABLE ROW LEVEL SECURITY; DROP POLICY IF EXISTS "Allow all poster_campaigns" ON poster_campaigns; CREATE POLICY "Allow all poster_campaigns" ON poster_campaigns FOR ALL USING (true) WITH CHECK (true); DROP POLICY IF EXISTS "Allow all campaign_sends" ON campaign_sends; CREATE POLICY "Allow all campaign_sends" ON campaign_sends FOR ALL USING (true) WITH CHECK (true);
