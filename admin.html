const BUSINESS = {
  phone: '7600617002',
  phoneDisplay: '+91 76006 17002',
  email: 'kesarinandanconsultancy@gmail.com',
  address: 'Shop no 11, Green Park Society...',
  website: 'https://kesarinandan.in',
  hours: 'Mon-Sat: 9AM–7PM | Sunday: 10AM–3PM',
  name: 'Kesari Nandan Consultancy',
  city: 'Surat, Gujarat'

Tip: In a production setup, move these settings to a Supabase table called settings for live editing without code changes.

⚙️ Supabase Setup Guide

Step 1: Create Supabase Project

Go to supabase.com → New Project → Fill details → Create.

Step 2: Run SQL

Open SQL Editor in Supabase → Paste the full content of supabase-setup.sql → Click Run. This creates tables and seeds all 24 services.

Step 3: Get API Keys

Go to Settings → API. Copy:
• Project URL → paste in SUPABASE_URL
• anon public key → paste in SUPABASE_ANON_KEY
Both in index.html and admin.html.

Step 4: Fix Admin RLS

For admin insert/update/delete to work with anon key, run in SQL Editor:

CREATE POLICY "Admin full access services" ON services FOR ALL USING (true) WITH CHECK (true);

⚠️ For production, use proper Supabase Auth instead of this open policy.

Step 5: Change Admin Password

Open admin.html → find const ADMIN_PASSWORD → change to your own secure password.
